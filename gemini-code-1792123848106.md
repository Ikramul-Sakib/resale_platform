# ValuLens (`resale_platform`) — System Architecture Specification

## 1. Architectural Overview
ValuLens is a modular, monolithic web application and REST API built with Python 3, Django (LTS), Django REST Framework (DRF), and PostgreSQL. It enforces a strict separation between presentation (Django Templates / DRF Serializers), domain business logic (Service Modules), and persistence (Django ORM + PostgreSQL native constraints).
